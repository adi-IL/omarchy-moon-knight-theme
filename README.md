Inspired by the dark psychological noir aesthetic of Warren Ellis, Declan Shalvey, and Alessandro Cappuccio's acclaimed *Moon Knight* runs. The palette builds upon a gradient from inky obsidian black (`#09070d`), through atmospheric Egyptian celestial violet (`#a855f7`), into stark lunar silver and pure alabaster white (`#ffffff`).

## Installation

Install with Omarchy's built-in theme installer (installs as `moon-knight`):

```bash
omarchy theme install https://github.com/adi-IL/omarchy-moon-knight-theme
```

Or clone manually into your user themes directory:

```bash
git clone --depth 1 https://github.com/adi-IL/omarchy-moon-knight-theme.git ~/.config/omarchy/themes/moon-knight
```

Activate the theme:

```bash
omarchy theme set moon-knight
```

Cycle wallpapers:

```bash
omarchy background next
```
